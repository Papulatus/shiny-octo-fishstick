# Practical AI Skill Hub

一个面向 AI Agent、开发者与研究工作流的实用技能/项目收藏库。这里**只保存结构化索引、使用说明和上游链接**，不镜像第三方代码。

## 使用方式

- 从 [CATALOG.md](CATALOG.md) 按主题浏览。
- 每个条目都说明：适合解决什么问题、上游项目/官网、许可证、接入建议及注意事项。
- 上游项目会持续变化；星标和活跃度仅记录为收录时的快照，使用前以原项目为准。

## 收录原则

1. 优先收录有明确上游、活跃维护、可核验许可证和清晰用途的项目。
2. 不把“能绕过任何网站限制”当作默认能力；使用爬虫与自动化前应遵守目标站点条款、robots、访问频率和法律要求。
3. 对需要登录态、浏览器资料或 API Key 的工具，先确认数据边界和授权范围。
