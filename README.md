# Practical AI Skill Hub

一个面向 AI Agent、开发者、研究与创作工作流的实用技能/项目收藏库。这里**只保存结构化索引、详细中文说明、风险边界和上游链接**，不镜像第三方代码。

## 如何使用

- 从 [CATALOG.md](CATALOG.md) 按主题浏览。
- 每个条目尽量覆盖：它是什么、适合什么、核心能力、接入方式、许可证、活跃度快照、工程/安全/合规注意事项。
- 上游项目会持续变化；星标、版本、许可与活跃度仅是收录时快照。实际采用前请复核上游 README、LICENSE、模型卡、服务条款与安全公告。

## 收录原则

1. 优先收录有明确上游、可核验许可证、清晰用途与持续维护迹象的项目/服务。
2. 每个条目需要写明能力边界；不将“技术上能做到”误写为“有权这么做”。
3. 对登录态、浏览器 profile、API Key、交易账户、代理、个人数据和企业文档采用最小权限与 Secret 管理，绝不写入仓库。
4. 对爬虫、自动化、市场数据和交易类项目，强调条款、数据许可、速率限制、人工审批、可审计性和风控。
5. 目录中的外部链接是研究入口，不是安全、质量、版权、可用性或商业授权保证。
