| 字段 | 信息 |

| 自我定位 | “The largest collection of free stuff on the internet” |
| 内容形态 | 社区维护的资源导航与主题目录 |

### 是什么

FMHY 是一个大量免费资源的索引站，主题包括 AI、音频、开发者工具、教育、文件工具、游戏、隐私、安全、下载、流媒体等。它是发现资源的起点，不是对每一条外链的安全、可用性、版权或合法性背书。

### 使用建议

- 用其作为关键词和候选服务发现工具，再回到原始服务检查官网、许可证、隐私政策和信誉。
- 任何下载站、破解/盗版相关、账户共享、绕过限制或高风险工具都不要直接采用；遵守版权、软件许可和当地法律。
- 下载文件先做来源校验、签名/哈希检查和恶意软件扫描；不要运行未知脚本或把主力浏览器 profile 授予陌生扩展。

**定位**：面向开发者和 Agent 的 API 发现入口。目录按 Animals、Art & Design、Authentication、Business、Documents、Email、Finance、Geocoding、News、Open Data、Security、Transportation 等主题汇集候选服务，并给出名称、简介、认证方式、HTTPS、CORS 等线索。

**正确使用方式**：把它当作“供应商发现索引”，不是 API 可用性、免费额度、长期维护、隐私安全或商用授权的担保。收录时 README 还含 APILayer 赞助/产品推广区，因此需区分目录条目与商业推广内容。

1. 从目录筛选候选后，必须阅读**该 API 官方文档与条款**，而非只看此仓库的简短描述。
2. 核查认证、免费层、计费、请求限制、地域、数据更新频率、弃用政策、SLA 与数据处理协议。
3. 所有 API Key 放在 Secret；实现请求超时、重试、缓存、熔断、错误观测和备用 provider。
4. 对涉及金融、身份、位置、邮件、个人数据的接口额外核查合规、数据最小化和跨境处理要求。
5. 给 Agent 接入 API 时只开放经过验证的少量工具，不要让其从目录中任意挑选并直接调用未知第三方服务。

## 邮箱助手（mail.seoml.com）— 邮箱服务导航

| 字段 | 信息 |
| --- | --- |
| 官网 | [mail.seoml.com](https://mail.seoml.com/) |
| 定位 | 分类整理个人、企业、教育、域名、邮箱应用、邮件服务和临时邮箱等入口 |

### 是什么与适用场景

这是邮箱工具的导航站，页面将临时邮箱、个人邮箱、域名邮箱、企业邮箱和客户端等分组。对需要快速比较邮箱服务、测试用一次性地址或寻找域名邮箱方案的人有参考价值。

### 临时邮箱的正确边界

临时邮箱适合低风险、非关键的测试注册和减少垃圾邮件；**绝不适合**银行、证券、交易所、GitHub、云服务、工作账号、找回密码、身份验证或任何长期账户。临时邮箱地址可能公开、可被回收、无法保证独占，也可能错过重要通知。

### 安全建议

- 账号安全使用受控的长期邮箱 + 强密码 + 密码管理器 + MFA/passkey。
- 企业/自定义域名邮件应评估 SPF、DKIM、DMARC、备份、管理员权限和审计能力。
- 导航站列出的第三方服务也需要逐个核查；不要因“临时”而发送证件、合同、验证码或密钥。
